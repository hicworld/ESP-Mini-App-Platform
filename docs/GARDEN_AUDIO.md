# 风来小院：声音设计

平台 0.4.4 / Garden 0.1.3。项目内编写的简短五声音阶旋律和程序合成音效，不含第三方音乐录音，也不依赖网络下载。

| 场景 | 声音 |
|---|---|
| 白天 | 48 秒循环，轻柔拨弦/木琴感旋律与低音分解伴奏 |
| 夜晚 | 64 秒循环，节奏更疏的八音盒感旋律 |
| 摸摸 | 轻铃上行回应 |
| 喂食 | 短促的三音节奏 |
| 浇水 | 连续下落水滴 |
| 有人靠近 | 欢迎铃音与短风声 |
| 按 A 或点天空 | 柔和风声 |

顶部天气详情里提供“音乐：开/关”和音量切换。0.4.4 根据实机反馈整体提高响度：档位为静音、轻柔、适中、响亮（0/35/55/75），默认 55；数字混音相对原版最高提高约 9 dB，ES8311 输出增益由 55 提高至 85。最大档测试峰值约为数字满幅的 26%，仍保留瞬态余量。关闭音乐仍保留互动音效，静音关闭全部声音。音量在本次系统运行期间保留，重启恢复默认；音乐开关在重新打开应用时恢复开启。未知昼夜时用白天旋律。

## Mosaico 接入

使用项目 BSP 的 ES8311 扬声器驱动，不自行更改板卡引脚定义。I2S 输出为 16 kHz、16-bit，左右通道复制同一合成声道。音频独立任务每次输出 20 ms 数据，不在 WASM/触摸回调中阻塞播放。只使用扬声器 API，没有调用麦克风采集 API。

音效播放期间降低音乐电平。每次只保留一个互动音效，150 ms 内重复请求限流；应用每次入口最多 4 次 audio 调用。退出、崩溃和打开系统设置都会清理播放状态并静音。codec 打开/写入失败会记录状态并停止继续输出，应用 UI 可继续运行。

新增 `audio` 权限和 `platform_audio(kind,value)` 系统接口：音乐仅可选 0/1/2，音效仅可选 1–5，0.4.4 的音量限制为 0–75。不接收文件路径、URL、PCM 指针或任意 I2S 命令。接口见 `sdk/include/platform.h`。包验签、目录解析、注册表重载与权限详情均识别 audio；Garden 0.1.3 要求平台至少 0.4.4。

## 试听与验证

`python tools/test_audio_host.py` 使用设备同一份整数 DSP 导出 `dist/audio/*.wav`。试听文件以最大允许软件音量 75 渲染；电脑与实物扬声器听感、响度不等同。

- `day-garden.wav` / `night-musicbox.wav`
- `pet-chime.wav` / `feeding.wav` / `watering.wav` / `welcome.wav` / `breeze.wav`

主机检查非静音输出、电平余量、缓冲区哨兵、分块连续性、停止清空和静音；新增板上自检夹具检查无权限、配额超限、非法音量。`audio_status` 显示 codec 返回值与累计 I2S 输出块数，能验证驱动写入，不能替代实际听音。电脑端结果不能替代实际听音和设备验收。
